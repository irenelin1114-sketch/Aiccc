# 煎心鍋貼｜線上訂單串接 Google Sheet 安裝說明

網站的「確認送出訂單」會把訂單送到 Google Apps Script（GAS），由 GAS 寫進 Google Sheet，並寄 Email 通知。

```
顧客在網站下單 ──► Google Apps Script（驗證、算金額、產生訂單編號）
                       ├─► Google Sheet「訂單」「訂單明細」
                       ├─► Email 通知店家（新訂單）
                       └─► Email 寄給顧客（訂單確認）

店家在 Sheet 把狀態改成「可取餐／已出貨／已取消」──► 自動 Email 通知顧客
每天 22:00 ──► Email 寄出當日營業摘要
```

## 一、建立 Google Sheet 與 Apps Script（約 10 分鐘）

1. 到 [Google 試算表](https://sheets.google.com) 建立一份新的空白試算表，命名為「煎心鍋貼 訂單」。
2. 上方選單點 **擴充功能 → Apps Script**。
3. 把編輯器裡預設的 `Code.gs` 內容全部刪掉，貼上本資料夾的 [`Code.gs`](Code.gs) 全部內容，按 **儲存**（磁碟片圖示）。
4. （選填）修改 `Code.gs` 最上方的 `CONFIG`：
   - `NOTIFY_EMAIL`：要收新訂單通知的 Email，多個用逗號分隔。留空就寄給你自己。
   - `DAILY_REPORT_HOUR`：每日摘要寄送時間，預設 22 點。
5. 左側點 **專案設定（齒輪）**，把「時區」設為 **(GMT+08:00) 台北**。
6. 回到編輯器，上方函式選單選 **`setup`**，按 **執行**。
   - 第一次會要求授權：選你的 Google 帳號 → 「進階」→「前往（不安全）」→「允許」。
     （這是你自己寫的腳本，Google 對未審核的腳本都會這樣提示。）
   - 完成後試算表會多出「訂單」「訂單明細」「商品價格」三個工作表。

## 二、部署成網頁應用程式

1. Apps Script 右上角 **部署 → 新增部署作業**。
2. 「選取類型」齒輪 → **網頁應用程式**。
3. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按 **部署**，複製「網頁應用程式網址」（`https://script.google.com/macros/s/……/exec`）。
5. 把網址貼到網站 `index.html` 裡的這一行（或直接把網址給 Claude 幫你貼）：

   ```js
   var ORDER_API_URL = '';   // ← 把網址貼在引號裡
   ```

6. 合併到 `main` 後，網站結帳就會真的送單了。結帳按鈕下方的說明文字也會從「此為示範網站…」自動改成「送出後門市將以電話與您確認訂單…」。

> **之後改了 `Code.gs` 要重新部署：** 部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署。
> 這樣網址不會變，網站不用改。

## 三、日常使用

| 工作表 | 用途 |
| --- | --- |
| **訂單** | 每筆訂單一列。改「狀態」欄（下拉選單）即可通知顧客。 |
| **訂單明細** | 每個品項一列，方便用樞紐分析表統計熱賣商品。 |
| **商品價格** | 網站結帳以這裡的價格為準。可改價格，或把「上架中」改成「否」暫停販售。 |

**狀態與通知**（顧客有填 Email 才會寄）：

| 狀態 | 會不會通知顧客 |
| --- | --- |
| 新訂單 | 下單時已寄確認信 |
| 製作中 | 不通知 |
| 可取餐 | ✅「餐點已完成，可以取餐囉」 |
| 已出貨 | ✅「禮盒已出貨」 |
| 已完成 | 不通知 |
| 已取消 | ✅「訂單已取消」 |

同一個狀態只會通知一次，寄出時間會記錄在「最後通知」欄。

## 四、安全與防呆

- **金額以後台為準：** 網站只送「商品代碼＋數量」，金額一律由 GAS 依「商品價格」工作表重新計算，改網頁也改不了價格。
- **資料檢查：** 後台會再檢查一次姓名、手機、Email、門市、時間、地址，以及宅配是否只有冷凍禮盒。
- **防重複下單：** 同一支手機 30 秒內不能重複下單，避免顧客連按兩次送出。
- **防機器人：** 表單裡有一個真人看不到的欄位，被填了就直接拒絕。
- **防公式注入：** 寫進試算表的文字如果以 `= + - @` 開頭，會自動加上 `'`，不會被當成公式執行。
- **訂單編號不重複：** 用 `LockService` 鎖住，同時有多筆訂單也不會重號。格式為 `JX` + 日期 + 當天流水號，例如 `JX261127-0001`。

## 五、注意事項與額度

- 免費 Gmail 帳號每天最多寄約 **100 封** Email，Google Workspace 帳號約 1,500 封。
- 目前沒有串接線上付款，顧客在取餐或收貨時付款。之後要加 LINE Pay、綠界等金流，可以再擴充。
- 網站的商品價格寫在 `index.html` 的 `menu`／`giftBoxes` 裡，改價格時請**兩邊一起改**。
  如果只改了試算表，顧客送單時會看到「金額已依最新價格更新」的提示，實際以試算表為準。
- 新增商品時，請在「商品價格」加一列，「商品代碼」要和網站上的 `id` 一樣。
